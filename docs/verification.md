# V1 验证记录

验证环境：Windows、Python 3.13.5、Node.js 22.23.2、Chrome；2026-09-22。

- Python：8 个测试通过，覆盖增量缓存、删除同步、失败时保留旧快照、LLM 变更复用向量、文本切分覆盖、单篇处理范围及 Provider 契约。
- TypeScript：14 个测试通过，覆盖中文/大小写/全半角检索、多词 AND、筛选、向量聚合、配置指纹、两端向量一致性、云接口响应排序、错误降级及接口数据边界。
- 浏览器：桌面与手机共 8 个场景通过，覆盖列表筛选、题目出处、关键词与语义搜索、原文定位、空结果、错误请求、404 与无横向溢出。
- Next.js 生产构建和 TypeScript 检查通过。页面预生成，搜索接口为动态 Node.js 路由。

## 容量场景

使用虚构示例扩展成 1000 篇、1000 个片段，将示例向量重复并归一化到 1536 维。此数据仅用于计算容量测试，不能用于评价真实模型质量。

| 项目 | 本次结果 |
| --- | --- |
| JSON 体积 | 26.57 MiB |
| 构造数据时的堆内存增量 | 18.69 MiB |
| 暖启动关键词搜索 | 16.15 ms |
| 本地语义相似度计算 | 15.49 ms |

不含磁盘首次读取、云端请求、网络、页面渲染耗时。内存增量不是服务总内存；更长原文会产生更多片段。测试在 `pnpm test` 中可复现，具体数值会波动。
