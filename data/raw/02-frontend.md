# 前端二面：把页面性能问题讲清楚

公司：远山互联（示例）
岗位：前端开发工程师
分类：前端
日期：2026-09-16
标签：React、性能优化、浏览器、TypeScript
摘要：从 React 组件设计进入浏览器渲染与首屏优化，最后以一个长列表场景考察性能分析和工程实践。

> 本文是用于产品演示的虚构面经。

面试先从最近的项目开始。我介绍了一个管理后台，包含复杂表单、图表和长列表。面试官更关注用户体验与可维护性。

- React 组件什么时候会重新渲染？useMemo 和 useCallback 分别适用于哪些情况？
- 浏览器从输入 URL 到页面显示经历了哪些步骤？
- 页面加载很慢，如何用性能面板定位瓶颈？
- 一万条数据的列表如何避免滚动卡顿？虚拟列表的原理是什么？
- TypeScript 的泛型和联合类型如何用于组件接口设计？

现场讨论了资源拆包、图片延迟加载和缓存策略。总结下来，需要能说出优化前后的测量方式，而不只是罗列优化名词。
